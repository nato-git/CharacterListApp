# CharacterListApp

CharacterListApp は、キャラクターの一覧管理を目的としたシンプルなアプリケーションです。ユーザーはキャラクター情報（名前、特徴、メモなど）を追加・編集・削除することができます。

## 特徴

- キャラクター一覧の表示
- 新規キャラクターの追加
- キャラクター情報の編集・削除
- 使いやすいインターフェイス

## インストール方法

リリースノートにある CRL.apk をダウンロードしてください。

## 使用方法

1. アプリケーションを起動します。
2. キャラクター情報を入力し、一覧から管理できます。
